# C# 문제 풀이 테스트 환경

이 프로젝트는 C#을 사용하여 알고리즘 문제를 풀고 로컬 환경에서 간편하게 테스트하기 위한 기본 템플릿입니다.

## 프로젝트 구조 및 파일 설명

*   **`Program.cs`**: 테스트 실행기입니다. `input` 파일에서 입력을 읽고, `answer` 파일의 정답과 `Solution` 클래스의 실행 결과를 비교하여 채점합니다. **이 파일은 수정할 필요가 없습니다.**
*   **`ISolution.cs`**: 모든 솔루션 클래스가 구현해야 하는 인터페이스입니다. `Main()` 메서드 시그니처를 정의합니다.
*   **`solutions/`**: 문제 풀이 코드를 작성하는 디렉토리입니다.
    *   **`template.cs`**: 실제 문제 풀이 로직을 작성하는 파일입니다. `Solution` 클래스의 `Main()` 메서드 내부에 코드를 작성합니다.
*   **`input`**: 문제의 입력 예시를 저장하는 텍스트 파일입니다. **테스트 케이스에 맞게 이 파일을 수정해야 합니다.**
*   **`answer`**: `input` 파일에 대한 정답 출력을 저장하는 텍스트 파일입니다. **테스트 케이스에 맞게 이 파일을 수정해야 합니다.**

## 사용 방법

1.  **입력 및 정답 파일 준비**:
    *   `input` 파일에 문제의 입력 예시를 작성합니다.
    *   `answer` 파일에 해당 입력에 대한 올바른 출력을 작성합니다. **주의:** 출력 끝에 불필요한 개행 문자가 포함되지 않도록 유의하세요.

2.  **솔루션 코드 작성**:
    *   `solutions/template.cs` 파일을 엽니다.
    *   `Solution` 클래스의 `Main()` 메서드 내부에 문제 풀이 로직을 작성합니다.
    *   **입력**: `Console.ReadLine()` 또는 `Console.In` 리더(Reader)를 사용하여 입력을 받습니다.
    *   **출력**: `Console.WriteLine()` 또는 `Console.Write()` (또는 `Console.Out` 라이터(Writer))를 사용하여 결과를 출력합니다.

3.  **테스트 실행**:
    *   터미널 또는 명령 프롬프트에서 다음 명령어를 실행합니다:
        ```bash
        dotnet run
        ```
    *   실행 결과가 `answer` 파일의 내용과 일치하면 "맞혔습니다." 메시지가, 일치하지 않으면 "틀렸습니다." 메시지와 함께 제출한 답과 정답이 출력됩니다.

## 주의사항

*   **출력 개행 문자**: `Console.WriteLine()`은 출력 문자열 끝에 자동으로 개행 문자를 추가합니다. 만약 문제에서 출력 끝에 개행 문자를 요구하지 않는다면, 마지막 출력은 `Console.Write()`를 사용하거나 다른 방식으로 개행 문자를 제어해야 합니다. `answer` 파일에도 개행 문자가 포함되지 않아야 정확한 비교가 가능합니다.
*   **빠른 입출력 사용 시**: `Program.cs`는 표준 입출력(`Console.In`, `Console.Out`)을 리디렉션하여 테스트를 수행합니다. 만약 `Solution` 클래스 내부에서 `new StreamReader(Console.OpenStandardInput())`와 같이 표준 스트림을 직접 열어서 사용하는 경우, `Program.cs`의 리디렉션 메커니즘이 작동하지 않아 로컬 테스트가 정상적으로 이루어지지 않을 수 있습니다. 로컬 테스트 시에는 `Console.ReadLine()` / `WriteLine()` 또는 `Console.In` / `Console.Out` 사용을 권장합니다. 실제 코딩 테스트 플랫폼에 제출할 때는 `Solution` 코드만 제출하므로, 해당 코드 내에서만 빠른 입출력을 사용해도 괜찮습니다.
*   **파일 인코딩**: `input`, `answer` 파일은 일반적으로 UTF-8 인코딩으로 저장하는 것이 좋습니다.
